# API Reference

This section is for developers integrating PyExtrusion into Python
applications, web backends, engineering tools, ERP/MES systems or automation
workflows.

## Main interfaces

- [Python API](python-api.md) — production, planning, sequences and comparison;
- [Engineering API](engineering.md) — source-traced mechanical and bounded
  thermal analytical tools;
- [Economics API](economics.md) — deterministic costs, revenue and margin;
- [JSON](json.md) and [CLI](cli.md) — persisted and command-line workflows;
- [Result fields](result-fields.md) and [errors](errors.md) — integration
  contracts.

The API reference documents callable interfaces, units, outputs and model
boundaries. It does not add assumptions that are absent from the public code.
