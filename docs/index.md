# PyExtrusion

**Engineering calculation toolkit for aluminium extrusion**

PyExtrusion is a deterministic Python toolkit for calculations related to direct aluminium extrusion, including process geometry, billet use, productivity, production planning, production sequences and multi-press comparison.

## Where to start

If you are new to PyExtrusion, begin with the **User Guide**.

If you want to understand the engineering meaning behind the calculations, use the **Technical Reference**.

If you are integrating PyExtrusion into software, use the **API Reference**.

## Documentation layers

- **User Guide** — learn by performing real tasks.
- **Technical Reference** — understand the public engineering basis.
- **API Reference** — build software around PyExtrusion.
- **Examples** — complete practical patterns.

> PyExtrusion supports engineering judgement. It does not replace press, die, alloy or plant-specific expertise.
