# About PyExtrusion

**PyExtrusion 0.19.0 — UNRELEASED CANDIDATE** is a deterministic engineering calculation toolkit for
direct aluminium extrusion.

- Project: PyExtrusion
- Python package: `pyextrusion`
- Website: https://pyextrusion.com
- PyPI: https://pypi.org/project/pyextrusion/
- Source: https://github.com/enrique-co/pyextrusion
- Author / maintainer: Enrique Calvo Ordonez
- Licence: Apache-2.0

The public package covers three working areas:

- production and planning;
- bounded analytical engineering models;
- deterministic production economics.

The project is designed around deterministic calculations, explicit units,
controlled validation, visible model boundaries and reusable interfaces for
engineering applications.
