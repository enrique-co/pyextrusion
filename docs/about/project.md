# About PyExtrusion

**PyExtrusion** is an engineering calculation toolkit for aluminium extrusion.

- Project: PyExtrusion
- Python package: `pyextrusion`
- Website: https://pyextrusion.com
- Author / maintainer: Enrique Calvo Ordonez
- Licence: Apache-2.0

The project is designed around deterministic calculations, explicit units, controlled validation and reusable interfaces for engineering applications.
